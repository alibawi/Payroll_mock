## 2. اللي يتغيّر (مطابقة لقطة ENKI ERP)

اللقطة تختلف عن الـ Sidebar العائم بمشروع Workspace القديم. الـ Shell الجديد:

### 2.1 الـ Sidebar (يمين بالعربي / يسار بالإنكليزي)
- شريط عمودي **ملتصق بالحافة** (مو عائم) على خلفية بيضاء، عرض ~260px، ينطوي.
- أعلاه: شعار **ENKI ERP** (الأيقونة + الاسم بخط serif مميّز) + زر طي القائمة (☰).
- قائمة الموديولات: كل بند = أيقونة + اسم + سهم `‹` (Chevron) يفتح الأقسام الفرعية. الترتيب كما باللقطة: الإدارة، إدارة الشحن، نقاط البيع، المبيعات، السوق، إدارة المخزون، **إدارة الموارد البشرية**، المالية، أمان، المشتريات، الأرشيف، الاستمارات، إدارة العلاقات مع العملاء، إدارة المشاريع، التصنيع، **+ الرواتب (الموديول الجديد)**.
- فاصل ثم أسفل الشريط: **الإعدادات · اللغة · الإشعارات**.
- البند النشط: خلفية خفيفة + لون Primary (وممكن تدرّج الـ brand حسب ما يتضح بالتنفيذ).

### 2.2 الـ Topbar
من اليمين لليسار (RTL):
1. اسم الشركة (`اسم الشركة`).
2. زر `+` (إنشاء سريع).
3. بحث عام بزر اختصار `K⌘` وكلمة Search.
4. شريط **Quick Access**: أزرار أفقية قابلة للتمرير لكل الموديولات (أيقونة + اسم) — الرواتب منها.
5. أقصى اليسار: مفتاح الثيم (شمس/قمر) + اسم المستخدم + صورة الأفاتار (مع نقطة حالة خضراء) + مبدّل الدور الوهمي.

### 2.3 الصفحة الرئيسية `/` (لوحة الموديولات)
- عنوان كبير: **«مرحباً بك في نظام إنكي»** + سطر فرعي «نظامك الشامل لإدارة الأعمال».
- شبكة بطاقات موديولات (5 أعمدة بالديسكتوب): كل بطاقة = **أيقونة داخل مربع ملوّن ناعم** + عنوان + وصف سطرين + **شارة اختصار** (`Ctrl+X`) أعلى البطاقة. 
- بطاقة الموديول عند hover: حدّ ولمعة بلون الموديول + سهم ↗ (مثل بطاقة الموارد البشرية الوردية باللقطة).
- كل موديول له لون مميّز لمربع الأيقونة (برتقالي، أخضر نعناعي، أصفر، سماوي، رمادي، وردي، أزرق فاتح…).
- **بطاقة الرواتب** (قرار موك أب): لون مميّز من عائلة الموارد البشرية (فوشيا/وردي غامق) وأيقونة `Wallet`/`Banknote`، اختصار `Ctrl+Y`، وصفها: «إدارة الرواتب والاستقطاعات والسلف وقسائم الدفع».
- بقية البطاقات (الشحن، المبيعات…) **بطاقات ديكور بدون صفحات** (تفتح `ComingSoon`) حتى تكتمل صورة النظام؛ الرواتب هي الوحيدة الحيّة، مع رابط لـ HR كـ Placeholder.

### 2.4 مبادئ عامة
- ثيمين (فاتح/غامق) + RTL/LTR، توكنز دلالية فقط (قاعدة CLAUDE.md #4).
- الأيقونات `lucide-react`، زوايا دائرية كبيرة (`rounded-2xl` للبطاقات)، ظلال خفيفة جداً.
- الأرقام المالية: فواصل آلاف + "د.ع" (دينار عراقي)، محاذاة رقمية LTR داخل النص العربي.

## 3. نقاط للتأكيد مع المستخدم
1. هل تريد نقل أسماء/ترتيب الموديولات بالـ Sidebar حرفياً من اللقطة (مع بقية الموديولات كديكور)؟ — **الافتراض**: نعم.
2. لون بطاقة/أيقونة الرواتب — **الافتراض**: فوشيا/وردي غامق.
3. اسم الشركة الوهمي بالـ Topbar — **الافتراض**: «شركة إنكي للحلول المتكاملة».
