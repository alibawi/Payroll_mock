# Spec — الموديول 4: العقوبات التأديبية والغياب/التأخير

> **المصدر**: الدراسة 3.3، **3.4** (الغياب والتأخير والعقوبات)، 4.4 (انضباط 14/1991)، 5.6 (قانون العمل 37/2015)، 8.2 (كيان 15 و2 `AttendancePenaltyPolicy`)، 8.3 (خطوات 3.5 و6.5)، 12.4، 11 (قرارات 14–18).

## 1. النطاق وصلته بالموديولات
- **`DisciplinaryPenalty`**: قرار إداري مالي (مبلغ/أيام/راتب شهر/نسبة) قابل للتقسيط، له سجلّ قانوني.
- **خصم الغياب والتأخير**: **محسوبان من الحضور** ولا يُدخلان يدوياً؛ الموديول يوفّر **شاشة معاينة/محاكاة** لسياسة الحضور (تُحرَّر فعلياً بالموديول 1).
- الفرق عن `PayrollInput`: `PayrollInput` مدخل حرّ لمرة واحدة؛ العقوبة كيان بسبب وقرار وحالة وتقسيط وتدقيق (3.4).
- يعتمد على: الموديول 2 (راتب الموظف لاحتساب `DaysOfPay`/`OneMonthSalary`)، الموديول 1 (السياسة والسقف).
- يغذّي: الموديول 5 (المحرك يلتقط أقساط العقوبة المستحقة).
- **غير مشمول**: العقوبات غير المالية (لفت نظر/إنذار/تنزيل درجة/فصل) — الكيان مالي فقط بالدراسة (G8).

## 3. دورة حياة الحالات
```
Draft ──approve──▶ Approved ──(أول استقطاع)──▶ Applying ──(كل الأقساط)──▶ Applied
  └─cancel─▶ Cancelled ◀─cancel─┘ (قبل أي استقطاع فقط)
```
| الحالة | الأزرار |
|---|---|
| Draft | تعديل، اعتماد، إلغاء |
| Approved | إلغاء (إذا لم يُستقطع شي) |
| Applying | عرض (لا إلغاء — **قرار موك أب**؛ الإلغاء الجزئي يحتاج قرار إداري) |
| Applied / Cancelled | عرض |

عكس دورة رواتب يعيد القسط المخصوم إلى `Pending` ويعيد `Applying → Approved` إن لم يبقَ غيره (مشتق).

## 4. قواعد العمل
| # | القاعدة | المصدر |
|---|---|---|
| P-1 | `computedAmount`: FixedAmount = value؛ DaysOfPay = value × معدّل اليوم؛ OneMonthSalary = راتب شهر كامل؛ PercentOfSalary = value% × الراتب | 3.4 |
| P-2 | معدّل اليوم = (الأساسي [+ بدلات محددة]) ÷ (أيام العمل أو أيام الشهر حسب `dayRateBasis`) | 3.4 / 8.3 |
| P-3 | **سقف الاستقطاع الشهري**: (عقوبات + قضائي + أقساط قروض) ≤ `GrossPay × maxMonthlyDeductionPercent` (الافتراضي 25%) | 3.4 / قرار #16 |
| P-4 | عقوبة `OneMonthSalary` **تُقسَّط دائماً** على أقل عدد أشهر يحترم السقف (لا دفعة واحدة) | قرار #18 / 5.6 |
| P-5 | عند تجاوز السقف بأي عقوبة أخرى: `AutoSpread` (رحّل الفائض للفترة التالية مع تنبيه بتقرير الدورة) أو `Block` (أوقف الاحتساب للموظف) حسب السياسة | قرار #17 / 8.3 |
| P-6 | مثال: راتب 900,000؛ سقف 25% ⇒ 200,000؛ عقوبة راتب شهر ⇒ 5 أشهر × 180,000 | 12.4 |
| P-7 | **خصم الغياب** = معدّل اليوم × أيام الغياب غير المبرَّر (بعد استبعاد الإجازات/العطل) — يخفّض Gross | 3.4 |
| P-8 | **خصم التأخير**: بعد فترة السماح (10د افتراضياً): PerMinute = دقائق × معدّل الدقيقة؛ Tiers = شرائح (1–15د=ربع يوم، 16–30=نصف يوم…)؛ CountBased = بعد N تأخيرات يُخصم يوم — يخفّض Gross | 3.4 / قرار #15 |
| P-9 | خصم الغياب/التأخير لا يخفّض الصافي أقل من صفر (NetPay ≥ 0) | 8.3 خطوة 9 |
| P-10 | كل عقوبة تحمل `decisionRef` و`decisionDate` و`issuedBy` و`reason` إلزامياً | 3.4 |
| P-11 | العقوبة لا تخفّض الأوعية الضريبية/التقاعدية (استقطاع بعد Gross) بعكس الغياب/التأخير | 3.4 |
| P-12 | لا عقوبة على موظف بلا تعويض نافذ | مشتق |
| P-13 | الموك أب: عند إنشاء عقوبة تظهر **معاينة جدول الأقساط الحيّة** وفق P-3/P-4 | مشتق |

## 6. مؤشرات (KPIs)
عقوبات بانتظار الاعتماد · عقوبات جارية التقسيط (المتبقي إجمالاً) · إجمالي المبالغ المخصومة هذا الشهر · موظفون قرب سقف الاستقطاع (>80%) · أكثر أقسام الغياب/التأخير (من الحضور).
