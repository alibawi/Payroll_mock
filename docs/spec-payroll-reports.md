# Spec — الموديول 6: التقارير ونهاية الخدمة والتوريد

> **المصدر**: الدراسة 1 (النطاق)، 3.2 (خطوة 7 التوريد)، 5.7 (نهاية الخدمة)، 8.2 (كيان 17)، 8.5 (Reporting)، 8.6 (تقارير)، 10 (Phase 7)، 11 (قرار 8)، 12.3.
> **مؤجّل بوعي (الدراسة 1)**: ملفات الجهات الرسمية بصيغتها المعتمدة + الإقرار السنوي — الموك أب يعرض كشوف التوريد **بكل الأرقام** وزر تصدير رسمي معطّل بـ«بانتظار المواصفة».

---

## 1. النطاق وصلته بالموديولات
- مخرجات الدورات (Posted/Paid) بشكل يُطبع/يُصدَّر: قسيمة الراتب، كشف الرواتب، ملف التحويل المصرفي، كشوف التوريد لجهات الدولة، سجلّ العقوبات (يُبنى بالموديول 4).
- **`EndOfServiceCalculation`**: احتساب لمرة واحدة عند الانفكاك (خاص) — بند/تقرير، **بلا accrual شهري** (قرار #8).
- يعتمد على: الموديول 5 بالكامل، الموديول 2 (سنوات الخدمة/آخر أجر)، بيانات HR الوهمية (رصيد الإجازات).

## 2. نموذج البيانات

### 2.1 `EndOfServiceCalculation` (`payroll/end-of-service.json`)
`id, employeeId, terminationDate, terminationReason (Resignation | ContractEnd | Termination | Dismissal-Disciplinary), serviceYears (يُشتق من تاريخ التعيين), lastWage, gratuityAmount, accruedLeaveDays, accruedLeavePay, arbitraryDismissalCompensation? (تعويض الفصل التعسفي إن وُجد), totalAmount, status, journalRef?, notes`.
- **`status`**: بالدراسة `Status` بلا قيم → **قرار موك أب** (G4): `Draft → Approved → Paid` (+`Cancelled`).

### 2.2 تقارير مشتقة (غير مخزنة، تُحسب من القسائم)
| التقرير | المحتوى |
|---|---|
| **قسيمة راتب فردية** | بيانات الموظف والفترة، سطور الاستحقاقات والاستقطاعات، الحضور، الصافي، الطباعة (Print CSS) |
| **كشف الرواتب الشهري** | جدول كل موظفي الدورة: الأساسي، البدلات، Gross، الاستقطاعات (بأعمدة)، Net، توقيع؛ تجميع حسب القسم/مركز الكلفة |
| **ملف التحويل المصرفي** | موظفو `Bank` فقط: الاسم، الحساب المصرفي، الصافي، إجمالي؛ تصدير CSV وهمي |
| **كشف توريد الضريبة** | إجمالي ضريبة الدخل + تفصيل بكل موظف |
| **كشف توريد التقاعد** (حكومي) | حصة الموظف + حصة الدولة لكل موظف |
| **كشف توريد الضمان** (خاص) | حصة العامل + حصة صاحب العمل + `establishmentFileNo` |
| **سجلّ العقوبات** | من الموديول 4 (رابط) |
| **تقرير الاستقطاعات المرحّلة (AutoSpread)** | العقوبات/الأقساط المؤجَّلة بسبب السقف (3.4) |
| **تقرير كلفة صاحب العمل** | حسب القسم/مركز الكلفة/الشهر (من KPIs) |

## 3. دورة حياة الحالات
- التقارير بلا حالات.
- **EndOfServiceCalculation**: `Draft → Approved → Paid` (+ `Cancelled` من Draft/Approved). الدفع Placeholder (سند وهمي + قيد معاينة).

## 4. قواعد العمل
| # | القاعدة | المصدر |
|---|---|---|
| T-1 | التقارير تتاح للدورات `Posted/Paid` فقط (وتُعرض علامة «مسودة» على غيرها) | 3.2 |
| T-2 | كشوف التوريد تُجمَّع لكل جهة (ضريبة/تقاعد/ضمان) لكل فترة؛ مجموعها = مجموع أسطر القسائم المصنّفة | 8.4 / 3.2 خطوة 7 |
| T-3 | التحويل المصرفي يستثني `Cash` ويُنبّه لمن ينقصه `bankAccountNo` | 8.2 |
| T-4 | **نهاية الخدمة للخاص**: مكافأة توضيحياً = **أجر أسبوعين عن كل سنة خدمة** (إن لم يكن العامل مشمولاً بمعاش) | 5.7 |
| T-5 | + **بدل الإجازات المتراكمة** (رصيد أيام الإجازة × معدل اليوم) + **تعويض الفصل التعسفي** إن وُجد | 5.7 |
| T-6 | **لا مكافأة** عند الفصل التأديبي (إنهاء لسبب تأديبي) | 5.7 |
| T-7 | معادلة الموك أب (توضيحية): `الأجر الأسبوعي = lastWage × 7 ÷ 30`؛ `gratuity = أجر أسبوعين × serviceYears` (الكسور تناسبية) — **قرار موك أب** لأن الدراسة لا تحدد أساس الأسبوع | مشتق |
| T-8 | الحكومي: لا يُحتسب (معاش تقاعدي) — الزر مخفي/يعرض «مشمول بالتقاعد الموحّد» | 4.5 / 6 |
| T-9 | لا `EndOfServiceCalculation` مكرر لنفس الموظف وتاريخ الانفكاك | مشتق |
| T-10 | المبالغ مقرّبة حسب `RoundingRule` | قرار #10 |

## 6. مؤشرات (KPIs)
إجمالي الضريبة المستحقة التوريد هذا الشهر · إجمالي التقاعد/الضمان المستحق (موظف+صاحب عمل) · عدد التحويلات المصرفية وإجماليها · مطالبات نهاية خدمة معلّقة · **كلفة صاحب العمل الشهرية**.

## 7. التكاملات (Placeholders)
- **التصدير**: PDF/CSV وهمي (تنزيل ملف فارغ/مثال ثابت، أو `window.print()` للقسيمة).
- **Finance**: توريد الأمانات ودفع الصافي ← «سند دفع» وهمي.
- **ملفات رسمية**: زر «تصدير بصيغة الجهة» معطّل بتلميح «بانتظار المواصفة» (الدراسة 1).
- **HR**: رصيد الإجازات وتاريخ التعيين للموظف.

## 9. ترتيب الأوامر (للبناء)
1. راوتات + Sidebar (`reports`, `remittances`, `end-of-service`).
2. mock-data (`end-of-service`, `remittance-status`) + API تجميع التقارير من القسائم (`/api/payroll/reports/*`).
3. مركز التقارير + كشف الرواتب.
4. قسيمة الراتب المطبوعة + ملف التحويل المصرفي.
5. كشوف التوريد (ضريبة/تقاعد/ضمان) + التحقق T-2.
6. نهاية الخدمة: لائحة + تفاصيل + حاسبة T-4..T-10 + State machine.
7. تقارير AutoSpread + كلفة صاحب العمل.
8. صلاحيات.
9. KPIs.
10. اختبار تدفق كامل: دورة Paid ← كشف رواتب ← قسيمة مطبوعة ← تحويل ← توريد؛ نهاية خدمة موظف خاص ← اعتماد ← دفع ← تبديل ثيم/لغة.
